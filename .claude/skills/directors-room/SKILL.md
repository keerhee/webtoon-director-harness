# Directors Room

1. Intake source handoff/layouts.
2. Narrative analysis.
3. Fan-out: Emotional / Cinematic / Webtoon-native.
4. Independent critic review.
5. Showrunner synthesis.
6. Continuity validation.
7. Quality gate using `config/quality_gate.yaml`.
8. If failing, create revision tasks and re-run affected reviews.
9. Export `direction_bible.md`, `panel_direction.yaml`, `continuity_state.yaml`, `critic_report.md`, `stage2_handoff.md`.
